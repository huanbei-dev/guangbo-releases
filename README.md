以下链接始终指向最新版本，新版本发布后无需更换链接：

- **Chrome**：https://github.com/huanbei-dev/guangbo-releases/releases/latest/download/chrome.zip
- **Edge**：https://github.com/huanbei-dev/guangbo-releases/releases/latest/download/edge.zip

## 安装方法

1. 下载对应浏览器的 zip 包并解压到本地目录
2. 打开浏览器扩展管理页（Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`）
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的目录即可
